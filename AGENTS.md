# Working principles

- Simplicity first. Less is more; add only what the current feature needs.
- Keep concerns separated and folders easy to browse.
- Prefer clear, small, maintainable code over clever abstractions.
- Build and verify one small feature at a time.
- Commit at each working milestone so changes are easy to reverse.
- Zero-cost first: use this VPS for the app and database, and free Cloudflare services when useful.
- Add paid services only when proven scale or requirements justify them.
